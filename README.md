# Arcade Lab · pilot demo

Static demo of the Arcade Lab pilot (HTML5 games catalogue): a browser copy running in an emulated dev-host. It is not the platform, not a certification and not a physical-device test.

Built files only; sources live in a private repository. Published with GitHub Pages: https://halinskiy.github.io/arcade-lab-demo/
